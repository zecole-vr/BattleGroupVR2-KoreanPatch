# BattleGroupVR2 한국어 패치

BattleGroupVR2(Steam · PCVR)의 비공식 한국어 패치입니다.

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 최신 버전 | **v.1.1.1** |
| 지원 게임 | Windows Steam / PCVR · 게임 빌드 26115335 (2026년 11월 11일 업데이트) |
| 설치 도구 | [ZECOLE VR 런처](https://github.com/zecole-vr/zecole-launcher) (Windows 10/11 64비트, WebView2, .NET Framework 4.8) |
| 제작 | 제콜 (ZECOLE) · [YouTube](https://www.youtube.com/@zecole) |

## 설치

**[ZECOLE_Launcher.exe 받기](https://github.com/zecole-vr/zecole-launcher/releases/latest/download/ZECOLE_Launcher.exe)** · 설치 없이 바로 실행 · 설치·업데이트·원본 복구를 모두 런처에서 합니다.

1. 게임을 종료합니다.
2. 런처를 실행하고 왼쪽 목록에서 **BattleGroupVR2**를 고릅니다.
3. **한글패치 설치**를 누르고 관리자 권한 요청에 **예**를 선택합니다.
4. 완료 메시지가 나오면 게임을 실행합니다.

- 지원하지 않는 버전이라고 나오면 게임이 업데이트된 것입니다. 새 한글패치가 나오면 런처에 자동으로 표시됩니다.
- 이전 패치라는 메시지가 나오면 Steam의 **게임 파일 무결성 검사** 후 다시 설치하세요.

## 복구

1. 게임을 종료합니다.
2. 런처의 BattleGroupVR2 화면에서 **원본 복구**를 누르고 관리자 권한 요청에 **예**를 선택합니다.
3. 원본 복원 완료 메시지가 나오면 게임을 실행합니다.

- 게임 폴더의 `BattleGroupVR2_Data/KoreanPatchBackup-v110`은 원본 백업이므로 보관하세요.
- 백업이 없거나 복원에 실패하면 **Steam 라이브러리 → 게임 속성 → 설치된 파일 → 게임 파일 무결성 검사**로 복구하세요.
