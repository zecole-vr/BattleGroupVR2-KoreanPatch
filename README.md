## 설치방법

1. [Releases](https://github.com/zecole-vr/BattleGroupVR2-KoreanPatch/releases/latest)에서 `BattleGroupVR2-KoreanPatch-v.1.0.0.zip`을 내려받습니다. `Source code` 파일은 설치용이 아닙니다.
2. 게임을 종료하고 ZIP을 모두 압축 해제합니다. **비밀번호: `zecole`**
3. `Install.cmd`를 더블클릭하고 관리자 권한 요청에 **예**를 선택합니다.
4. 게임 경로를 찾지 못하면 BattleGroupVR2 설치 폴더를 선택합니다. 완료 메시지가 나오면 게임을 실행합니다.

지원하지 않는 버전 또는 이전 패치라는 메시지가 나오면 Steam의 **게임 파일 무결성 검사** 후 다시 설치하세요.

## 복구방법

1. 게임을 종료합니다.
2. `Restore.cmd`를 더블클릭하고 관리자 권한 요청에 **예**를 선택합니다.
3. 원본 복원 완료 메시지가 나오면 게임을 실행합니다.

게임 폴더의 `BattleGroupVR2_Data/KoreanPatchBackup-v100`은 원본 백업이므로 보관하세요. 백업이 없거나 복원에 실패하면 **Steam 라이브러리 → 게임 속성 → 설치된 파일 → 게임 파일 무결성 검사**로 복구하세요.
